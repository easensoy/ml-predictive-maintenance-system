The template follows the grading rules by construction, so its pass rates check that the cases and the grader agree; they say nothing about the quality of model-written notes. The language-model side has not been run: no model call has been made, so no model fidelity, abstention, latency or cost figure exists. Running it needs an API key in `ANTHROPIC_API_KEY` and `uv sync --extra notes`, then `python -m predmaint.notes eval --claude`.
